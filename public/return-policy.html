Return Policy

Last updated: January 2026

We accept returns on most items within a specified period. Please read our return policy carefully before making a purchase.

Return Period

Items may be returned within 7 days of delivery. Items returned after this period will not be accepted.

Return Conditions

To be eligible for a return, items must:

  • Be unworn and unwashed
  • Have all original tags attached
  • Be in original packaging
  • Not be damaged by the customer

How to Initiate a Return

To start a return:

  • Email us at contact@ridinuul.com with your order number
  • Include photos of the item you wish to return
  • State the reason for the return
  • Wait for return approval and shipping instructions

Return Shipping

  • For defective or incorrect items: We will cover return shipping costs
  • For change of mind returns: Customer is responsible for return shipping costs
  • We recommend using a trackable shipping method

Exchanges

We offer exchanges for different sizes or colors, subject to availability. To request an exchange:

  • Contact us within 7 days of receiving your order
  • Specify the item and the size/color you want instead
  • Return the original item following our return process

Non-Returnable Items

The following cannot be returned:

  • Items marked as "Final Sale"
  • Undergarments and intimate apparel
  • Custom or personalized items
  • Items purchased during clearance sales
